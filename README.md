
Key Features:
	•	Personal Workout Calendar – Track your daily exercises and streaks
	•	Custom Profile – Save personal data like name, age, height, weight, and goals
	•	Reminders & Motivation – Set custom workout reminders with motivational quotes
	•	Rewards System – Earn stars and achievements for consistent training
	•	Shuffle Workout – Get a random workout suggestion when you need inspiration
	•	Simple Navigation – Clean, intuitive UI for an effortless user experience

Tech & Tools
	•	Figma – UI/UX design and interactive prototype
	•	Trello (Scrum Board) – Project planning & sprint management
	•	GitHub – Version control and collaboration
	•	Firebase - For Auth and Personal workout with tracking
